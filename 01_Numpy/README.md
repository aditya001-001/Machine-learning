# 🔢 NumPy Foundational Computing

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![NumPy](https://img.shields.io/badge/NumPy-1.20+-blueviolet.svg?style=flat&logo=numpy&logoColor=white)](https://numpy.org/)

This directory covers high-performance array operations and numerical computations using **NumPy (Numerical Python)**. NumPy is a critical foundation for machine learning as it enables fast vector and matrix calculations, which are standard for handling dataset features.

---

## 📖 Notebooks & Contents

### 📓 [01_NumPy_Basics.ipynb](./01_NumPy_Basics.ipynb)
A comprehensive guide covering:
*   **Array Properties**: Creating homogeneous 1D & 2D arrays, list vs. array differences.
*   **Range Generation**: Generating numeric sequences with `arange()` and `linspace()`.
*   **Indexing & Slicing**: Multi-dimensional matrix indexing and row/column extraction.
*   **Random Number Generation**: Uniform/integer sampling (`randint`), random seeding, and unique element counts.
*   **Reshaping & Resizing**: Changing matrix dimension structures (`reshape` vs `resize`).
*   **Mathematical Foundations**: Manual calculation of Variance and Covariance using NumPy vectorized operations.

---

## ⚙️ Core Concepts Covered
- Memory-efficient data storage (ndarrays).
- Vectorization and avoiding explicit loops.
- Broad-casting arithmetic operations.
- Statistical analysis from scratch (Variance, Covariance).
