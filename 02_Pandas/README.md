# 🐼 Pandas Structured Data Manipulation

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg?style=flat&logo=python&logoColor=white)](https://www.python.org/)
[![Pandas](https://img.shields.io/badge/Pandas-1.3+-darkblue.svg?style=flat&logo=pandas&logoColor=white)](https://pandas.pydata.org/)

This directory covers data manipulation and analysis using **Pandas**. Pandas provides fast, flexible, and expressive data structures (DataFrames and Series) designed to make working with structured (tabular, multidimensional) data both easy and intuitive.

---

## 📖 Notebooks & Contents

### 📓 [01_Pandas_Fundamentals.ipynb](./01_Pandas_Fundamentals.ipynb)
A consolidated, comprehensive guide combining base syntax, indexing models, and datetime formatting operations:
*   **Data Ingestion & Inspection**: Loading CSV files, checking metadata (`info()`, `dtypes`), and non-null counts.
*   **Indexing & Slicing**: Selecting columns, slicing rows, and utilizing `.iloc` (integer-location) and `.loc` (label-location).
*   **Filtering**: Using boolean masks to filter data rows based on single or compound criteria.
*   **Aggregations & Grouping**: Running custom aggregates with `agg()`, splitting data by categories with `groupby()`, and using `get_group()`.
*   **DateTime Operations**: Converting columns to datetime datatypes and extracting features like Year, Month, and Day.
*   **Cheat Sheet**: A reference guide summarizing core Pandas commands for quick lookup.

---

## ⚙️ Core Concepts Covered
- Managing tabular datasets (DataFrames) and arrays (Series).
- Conditional data querying.
- Multi-index analysis and group-wise statistics.
- Dynamic feature extraction from timestamps.
