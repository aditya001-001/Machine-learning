# 📊 Model Evaluation & Hyperparameter Tuning

This directory contains notebook implementations covering classification metrics, error diagnosis, and hyperparameter search techniques.

## 📖 Notebooks

### 📓 [01_Classification_Metrics.ipynb](./01_Classification_Metrics.ipynb)
- **Concept**: Evaluating classification accuracy and quality metrics.
- **Topics**:
  - **Confusion Matrix**: True Positive, True Negative, False Positive, and False Negative tables.
  - **Precision**: Quantifying predictive accuracy of class label recommendations.
  - **Recall**: Evaluating coverage of positive classes.
  - **F1-Score**: Harmonic mean of Precision and Recall.
  - **Accuracy**: General sample correct rates.

### 📓 [02_GridSearchCV_and_Hyperparameter_Tuning.ipynb](./02_GridSearchCV_and_Hyperparameter_Tuning.ipynb)
- **Concept**: Automated selection of model parameters to improve validation accuracy and generalization.
- **Topics**:
  - **GridSearchCV**: Setting up parameter grids for estimators and running cross-validation pipelines.
  - **Hyperparameter Tuning**: Fine-tuning Decision Trees and Random Forests on structured datasets.
