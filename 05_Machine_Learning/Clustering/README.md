# 🧩 Unsupervised Clustering

This directory contains implementations of unsupervised clustering algorithms that group unlabeled data based on feature similarities.

## 📖 Notebooks

### 📓 [01_KMeans_Clustering.ipynb](./01_KMeans_Clustering.ipynb)
- **Concept**: Partitioning data into $K$ distinct clusters.
- **Topics**:
  - **Synthetic Data Clustering**: Creating blobs of synthetic elements using `make_blobs` to isolate core algorithm behavior.
  - **Elbow Method**: Selecting the optimal cluster count $K$ by plotting Within-Cluster Sum of Squares (Inertia) against various values of $K$.
  - **Centroids Visualization**: Plotting raw clusters alongside coordinates of optimized centroids.
  - **Portfolio Practice**: Utilizing the `collegePlace.csv` student dataset to cluster records based on age, CGPA, and placement likelihood.
