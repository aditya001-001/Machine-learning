# 🎯 Classification Models

This directory contains implementations of classification algorithms that predict discrete labels.

## 📖 Notebooks

### 📓 [01_Logistic_Regression.ipynb](./01_Logistic_Regression.ipynb)
- **Concept**: Theoretical breakdown of Logistic Regression.
- **Topics**: Sigmoid activation function, cross-entropy cost function, gradient descent optimization, and regularization strategies (L1/L2).

### 📓 [02_Decision_Trees.ipynb](./02_Decision_Trees.ipynb)
- **Concept**: Decision Tree splitting nodes.
- **Topics**: Gini Impurity vs. Entropy splitting criteria, and basic tree classification pipelines.

### 📓 [03_Ensemble_Random_Forest.ipynb](./03_Ensemble_Random_Forest.ipynb)
- **Concept**: Combining predictions from multiple models via Bagging.
- **Topics**: Random Forest ensembles and general bagging techniques.

### 📓 [04_RandomForestClassifier.ipynb](./04_RandomForestClassifier.ipynb)
- **Concept**: Random Forest classifier.
- **Topics**: Staging, building, and checking feature importances of tree-based ensembles.

### 📓 [05_XGBoostClassifier.ipynb](./05_XGBoostClassifier.ipynb)
- **Concept**: Gradient-boosted decision trees.
- **Topics**: Training extreme gradient boosting models on tabular classification tasks.

### 📓 [06_GaussianNaiveBayes.ipynb](./06_GaussianNaiveBayes.ipynb)
- **Concept**: Probabilistic classifier based on Bayes' theorem.
- **Topics**: Prior, likelihood, and posterior probability modeling.
