# 📈 Regression Models

This directory contains implementations of regression algorithms that predict continuous values.

## 📖 Notebooks

### 📓 [01_Linear_Regression.ipynb](./01_Linear_Regression.ipynb)
- **Concept**: Simple linear regression ($y = mx + c$).
- **Application**: Mapping Years of Experience to Salary prediction.
- **Key Methods**: Train-test splitting, fitting Scikit-Learn linear regression models, coefficient and intercept inspection.

### 📓 [02_Polynomial_Regression.ipynb](./02_Polynomial_Regression.ipynb)
- **Concept**: Fitting non-linear curves to data.
- **Application**: Generating polynomial feature projections and training regression models on non-linear datasets.

### 📓 [03_Regression_Practice.ipynb](./03_Regression_Practice.ipynb)
- **Concept**: Guided practice problems covering multiple datasets.
- **Application**: Regression application on housing datasets and study hours correlations.

### 📓 [04_Model_Performance_and_Overfitting.ipynb](./04_Model_Performance_and_Overfitting.ipynb)
- **Concept**: Diagnosing model performance and solving overfitting vs. underfitting.
- **Evaluation Metrics**: Mean Absolute Error (MAE), Mean Squared Error (MSE), Root Mean Squared Error (RMSE), and $R^2$ Score.

### 📓 [05_RandomForestRegressor.ipynb](./05_RandomForestRegressor.ipynb)
- **Concept**: Non-linear ensemble model based on bagging decision trees.
- **Application**: Random Forest regressor implementations for complex datasets.

### 📓 [06_XGBoostRegressor.ipynb](./06_XGBoostRegressor.ipynb)
- **Concept**: Gradient Boosting tree-based regressor for high-performance predictions.
- **Application**: XGBoost training pipeline on tabular features.
