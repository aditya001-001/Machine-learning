This directory covers data visualization techniques using **Matplotlib** and **Seaborn**. Data visualization is key to Exploratory Data Analysis (EDA) because it helps detect outliers, identify features' distributions, and observe linear or non-linear relationships.

---

## 📖 Notebooks & Contents

### 📓 [01_Matplotlib_Fundamentals.ipynb](./01_Matplotlib_Fundamentals.ipynb)
Covers basic plotting paradigms using Matplotlib:
*   **Line Plots**: Visualizing trends over time, sorting inputs, and grouping data for continuous plotting.
*   **Bar Plots**: Distribution of categorical fields and count comparisons.
*   **Pie Charts**: Proportional parts of a whole, showing percentage slices using `autopct`.

### 📓 [02_Seaborn_Advanced_Plots.ipynb](./02_Seaborn_Advanced_Plots.ipynb)
Focuses on advanced statistical plotting and syntax comparison:
*   **Scatter Plots**: Visualizing 2D numerical relationships and linear clusters.
*   **Box Plots**: Identifying outliers and looking at data distributions (quartiles/IQR).
*   **Correlation vs. Covariance**: Exploring the strength and direction of relationships between multiple feature columns.
*   **Matplotlib vs. Seaborn**: Syntax comparisons (e.g. using `hue` for multi-dimensional groupings in Seaborn).

### 📓 [03_Visualization_Exercises.ipynb](./03_Visualization_Exercises.ipynb)
A collection of practice problems and questions applying Pandas manipulations and visualization techniques on three distinct datasets:
- **Superstore Sales**: Analyzing business revenue and category distributions.
- **Student Performance**: Correlating study habits with academic grades.
- **Google Play Store**: App ratings, size, and category histograms.

---

## ⚙️ Core Concepts Covered
- Designing custom figures, axes, and styles.
- Distinguishing between categorical vs. continuous plots.
- Bivariate and multivariate correlation analysis.
- Visual outlier identification.
